# 🔍 Digital Forensics Using Autopsy

## Experiment No. 5

**Subject:** Digital Forensics  
**Experiment:** Use Autopsy to Create a Case and Import Evidence

---

## 🎯 Aim

To use Autopsy to create a forensic case and import evidence for digital forensic analysis.

---

## 📝 Description

Autopsy is an open-source digital forensics platform used for analyzing and extracting data from digital devices.

---

## 🛠️ Requirements

- Autopsy
- Forensic Disk Image
- Windows / Linux / macOS
- `.E01` evidence files
